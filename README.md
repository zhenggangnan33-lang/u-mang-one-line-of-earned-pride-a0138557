Entry for the [make.fun](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) bounty **One Line of Earned Pride**.

## The entry

`main.ts` writes a single line of text — a quiet, earned moment of pride for someone in a scene — to `/output/entry.txt`. The line is 133 characters, within the competition's 1–240 character limit. Before writing, the program validates the line against the gate itself (1–240 characters, not only white space) and exits with an error if it would fail.

## Run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set).
